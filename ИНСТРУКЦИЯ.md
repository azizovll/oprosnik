# Как запустить опросник

## Страницы
- `/` — для студентов: выбирают группу → Пацаны/Девушки → своё имя → проходят опросы.
- `/admin` — для вас: создание опросов, открыть/закрыть, результаты, кто не ответил, CSV.

## 1. Google Таблица (база данных)
1. Создайте новую таблицу на https://sheets.google.com
2. **Расширения → Apps Script**, удалите всё и вставьте код из `google-apps-script.gs`.
3. В строке `const ADMIN_KEY = "..."` поставьте свой пароль для админки.
4. Сохраните (💾).
5. **Начать развёртывание → Новое развёртывание** → ⚙️ **Веб-приложение**:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
6. Разрешите доступ (Дополнительно → Перейти к проекту → Разрешить).
7. Скопируйте ссылку `https://script.google.com/macros/s/.../exec` и вставьте её в `config.js` → `SCRIPT_URL`.

> Если потом меняете код Apps Script: **Развёртывание → Управление развёртываниями → ✏️ → Версия: Новая → Развернуть**. Ссылка останется той же.

## 2. Публикация на Vercel
В терминале в папке проекта:
```
npx vercel login
npx vercel --prod
```
На вопросы при первом запуске можно отвечать Enter (настройки по умолчанию).

## 3. Изменить список людей
Отредактируйте `people.js` и снова выполните `npx vercel --prod`.

## В Google Таблице
- `_опросы` и `_ответы` — служебные листы, их **не редактируйте руками**.
- Для каждого опроса создаётся отдельный лист «Название (id)» с понятной таблицей ответов.
